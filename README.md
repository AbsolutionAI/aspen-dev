# aspen-dev

**Canonical development company backend for AspenGrove**

Part of the three-product organism:
- **AspenOS** — agentic-first operating system / control plane
- **Aspen Sentinel** — OSINT + HITL command dashboard
- **aspen-dev** — this repository (development company backend)

## Ownership

aspen-dev is the **single source of truth** for:
- Paperclip company definitions and org charts
- Hermes personas / souls / skill catalogs
- Compound Engineering gates
- Packaging mesh references and redacted blueprints
- Self-pruning / self-growing policy (180-day horizon)
